## 🚀 ━━━ Quick Start ━━━ 🚀

### For Users - Just Start!

**No install needed! Just start Pamela and enjoy!**

</div>

<br>

<div align="center">

### 📲 Start Pamela On Telegram

</div>

    1. Tap Start on Telegram - @Pamela_cullen_bot
    2. Press START
    3. Add @Pamela_cullen_bot to your group
    4. Make her Admin - For Pin / Ban / Mute to work!
    5. Done! Relax! Pamela will ping you!

<br>

<div align="center">

### 👩‍💻 For Developers - Run Locally

</div>

    git clone https://github.com/YOUR-USERNAME/pamela-bot.git
    cd pamela-bot
    pip install -r requirements.txt

Create .env file:

    BOT_TOKEN=YOUR_BOT_TOKEN_HERE
    CHANNEL_IDS=YOUR_GROUP_ID_HERE

Run:

    python main.py
